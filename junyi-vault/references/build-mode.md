# 搭建模式｜默认骨架上的有限个性化

## 目标

让第一次使用 Obsidian 的超级个体、老板或个人工作者，在不理解知识管理术语的情况下，也能得到一套能立即放入真实材料的 V0 结构。

不要从九项经营访谈开始，也不要让本人凭空设计目录。默认骨架承担大部分结构，问题只负责校准名称、拆分和隐私边界。

## 默认 V0

| 默认目录 | 负责什么 | 常见内部区分 |
|---|---|---|
| `01｜事业与项目/` | 正在推进的事业、工作和项目上下文 | 当前项目、业务或工作单元 |
| `02｜个人与生活/` | 个人成长与生活责任 | 个人资料、成长、生活；家庭或健康尚未独立时也先放这里 |
| `03｜知识与资产/` | 输入和跨项目复用资产 | 学习输入、可复用判断／方法／案例／模板／Skill |
| `99｜收件箱/` | 暂未判断去向的临时材料 | 只作临时入口，必须定期清理 |

这四个名称是默认候选，不是固定答案：

- 没有“事业”语境时可改为“工作与项目”；
- 学习输入与成熟知识是两个状态，可以在“知识与资产”内部区分，不必默认成为两个顶层目录；
- 内容创作默认跟随业务或项目，不因本人会发内容就自动独立；
- `USER.md` 是后续工作台开通文件，不属于“个人档案”文件夹，也不由本 Skill 生成。

## 只问 2 个必答问题＋1 个隐私选答

### 必答 1｜长期责任

> 你的工作台需要长期照顾哪些方面？请从事业／工作、个人成长、家庭、关系、健康、财务中选最重要的 2–4 项，也可以改成自己的说法。

只用答案判断默认目录是否需要改名或拆分。不要立刻把每个选项都建成顶层文件夹。

### 必答 2｜三个真实材料测试

> 说出最近一周真正处理过的 3 份资料、任务或项目。你以后会用什么词去找它们？

对每一项给出首选路径。本人认为“我不会去那里找”时，才调整结构。

### 隐私选答

> 哪些家庭、客户、财务、健康或商业资料，需要独立存放，或默认不允许 AI 读取？

区分三种处理：普通目录边界、AI 默认排除规则、独立 Vault／外部系统。不要把普通文件夹描述为真正的权限隔离。

## 调整规则

默认只允许改名、合并、拆分或最多新增两个顶层领域，最后通常保留 3–6 个顶层文件夹。

某项内容在以下三项中满足至少两项，才升为顶层领域：

1. 经常产生或查找；
2. 是长期独立责任；
3. 有明显的检索或隐私边界。

常见判断：

- **家庭**：如果是长期责任且有隐私边界，把“个人与生活”拆成“个人成长”和“家庭生活”；否则先作为子目录。
- **内容创作**：如果只是某项业务的营销环节，留在该业务或项目中；只有内容本身是独立主业且高频检索时才独立。
- **关系**：项目内客户留在项目；跨多个项目长期按人物检索时，可以独立为“关系与协作”。
- **时间与复盘**：只有本人长期按日期找材料且已有稳定复盘流程时才独立。
- **财务与健康**：频率不高时留在个人、家庭或事业内部；涉及独立责任和隐私时再拆分。
- **多项事业**：优先作为“事业与项目”下的业务单元或项目，不自动把每项事业都升为顶层。

## 结构压力测试

输出方案前逐条检查三份真实材料：

1. 本人是否能在 5 秒内说出首选位置？
2. 是否总要跨三四个目录才能放下？
3. 未来找回时会先想这个目录名吗？
4. 是否出现两个同样合理、边界说不清的权威家？

任一材料没有清楚首选位置时，只做一个最小调整，再重新测试。不要为了覆盖所有未来可能性预建空目录。

## 结构方案必须包含

1. **默认骨架映射**：四项默认能力分别由哪个实际目录承担；
2. **最终 3–6 个顶层目录**：名称、收什么、不收什么、隐私边界；
3. **三个真实材料路径**：首选位置和理由；
4. **本次调整**：相较默认骨架做了哪些改名、合并、拆分或新增；
5. **暂不建立**：哪些分类当前证据不足；
6. **操作预览**：本人确认结构后才生成 manifest。

## 创建边界

课堂或后续个人工作台流程中，默认只创建已确认的目录。只有本人明确要把 `junyi-vault` 作为独立知识库工具使用时，才可另外提议 `知识库说明.md` 或 `索引.md`，仍需单独确认。

本 Skill 不生成：

- `USER.md`；
- `CLAUDE.md`／`AGENTS.md`；
- 工作台入口或当前主线；
- 项目 `README.md`；
- 对外发布、权限配置或自动化。

操作 manifest 示例：

```json
[
  {"type": "directory", "path": "01｜事业与项目"},
  {"type": "directory", "path": "02｜个人成长"},
  {"type": "directory", "path": "03｜家庭生活"},
  {"type": "directory", "path": "04｜知识与资产"},
  {"type": "directory", "path": "99｜收件箱"}
]
```
