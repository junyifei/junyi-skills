# 微信公众号长文协作

用同一套公开方法服务不同创作者：Skill 保存流程、输入输出和质量门禁；创作者自己的定位、语料、路径、授权与发布规则留在其私人工作区。不要在 Skill 中内置或寻找某位创作者的私人资料。

## 启动门禁

1. 先判断任务状态：从零创作、从素材到大纲、续写、改稿、终审、标题检查或配图规划。
2. 只读取本次对话、工作区已声明规则或使用者明确指定的配置和材料。不得搜索未授权的私人目录。
3. 按 [配置契约](references/configuration-contract.md) 检查最小配置；读取 1–2 篇与本次任务同类型、且明确授权的本人完整范文。只读风格摘要不算完成。
4. 若最小配置不完整，或没有至少 1 篇授权全文范本，进入**初始化模式**：只交付缺口清单、素材盘点和可选大纲，不写完整正文，也不声称已掌握使用者语气。
5. 配置齐全后，根据任务已完成状态从对应阶段开始，不机械重跑已确认步骤。

文件路径只用于内部定位，不是文章内容。任何交付中的“来源”“材料”“风险”或“配置”字段，都只显示可公开的文档标题、来源标签或使用者给出的名称；不得回显绝对路径、用户目录、隐藏目录、临时目录、仓库检出位置或配置文件的物理位置。即使路径来自本轮授权，也只代表允许读取，不代表允许披露。

若任务明确要求“零新增事实／不增加新事实”，进入**零新增编辑模式**。这一模式高于写作 DNA、授权范本、默认 CTA、篇幅目标和“增强画面／情绪／互动”的一般建议，待改原文是唯一内容词典。先从待改原文建立允许使用的事实、动作、环境、心理、判断、比喻和 CTA 清单；改写中的每个内容性句子都必须能逐句指向原文。不得新增天气、风、光线、身体反应、停顿、动作、内心独白、回忆、动机、对话、比喻、因果桥、读者邀请或联系方式，即使它们听起来合理、自然或更有画面。无法指向原文的句子直接删除，不用“可能”“仿佛”等措辞保留。

零新增编辑默认采用**抽取式编辑**：只允许删除原句、重排原句、截取不改变含义的原句片段，以及修改标点、段落和小标题位置；不得自由改写或新写承上启下的句子。移动原文已有内容时，也不允许补写新的过程或解释。例如，原文只有“项目结束后我调整了计划”，不能补成“我独自消化了一晚，终于想明白下一步”；原文只有“工具节省了时间”，不能补成“我因此停下来，看见了过去忽略的自己”。拿不准时逐字保留原句或少改，不追求改写幅度。只有使用者明确授权“可以换表达，但不改事实”时，才允许不改变主体、动作、对象、程度、时间、动机、情绪、判断和因果关系的轻度转述。

零新增编辑中的 CTA 状态只从待改原文和本轮明确确认中读取。原文没有 CTA 时，默认 CTA、联系方式和发布规则全部停用；除非使用者本轮明确要求新增，否则 CTA 终审写“不适用”，不得把“缺少 CTA”列为问题，也不得在改写、建议或待判断项中引入 CTA。

授权范本是**语感参照，不是本次事实、观点或词句来源**。在读取范本前后都要保持来源隔离：范本中的经历、判断、比喻、金句、第一人称心理、CTA 和内容性短语，不得改写后移入新稿。任何第一人称事实、动机、感受、判断和因果，都必须能回到本次素材或作者本轮确认；无法回读时标 `[待补]`，不得用范本补齐。

配置优先级：本次明确要求与授权 > 工作区当前生效规则 > 指定的作者资料和语感来源。发生冲突时按高优先级执行，并说明被覆盖的规则。

## 0—11 阶段流程

### 0. 起心动念与传播任务

用一句话分别写清：为什么现在写、最想让谁读、希望对方读完理解或采取什么行动。区分建立信任、分享经验、解释方法和邀请行动，不用平台流量目标替代真实写作目的。

### 1. 角度与七类内容判断

从 2–3 个可被材料支撑的角度中选择一个。判断主类型与最多一个辅类型：

| 类型 | 核心任务 |
| --- | --- |
| 工具 | 解决一个明确问题，给出可执行方法与适用边界 |
| 角度 | 用证据修正一个常见看法 |
| 余韵 | 让真实经历或观察在读者心中继续发生 |
| 系统 | 解释多个判断怎样组成一套可复用方法 |
| 人物 | 通过选择、冲突和变化呈现一个人 |
| 专论 | 界定问题、展开论证、处理反例和边界 |
| 实录 | 按真实时间线复盘过程、决策和未完成状态 |

反直觉和反共识必须由事实、真实经历或完整推理支撑；没有信息增量时不制造对立。

### 2. 素材盘点与内容锁定

建立“内容锁定单”，至少包含：

```text
写作目的：
目标读者：
主类型 / 辅类型：
一句话核心判断：
原始材料与来源：
已确认事实、数字、原话和时间线：
作者已经表达过的判断：
不可公开项与隐私边界：
CTA 与发布规则：
仍缺的关键材料：
```

按 [证据与隐私](references/evidence-and-privacy.md) 区分事实、作者判断、可核对原话、推断、待确认和不可公开项。没有支撑的位置标 `[待补]`；不得编造场景、反应、对话、数字、心理活动、结果或因果。

内容锁定后，后续新增、删除或改变核心事实、判断、人物边界和 CTA，都要在交付中列出差异并请使用者确认。

大纲中的候选开头、过渡句、标题解释、比喻、示范 CTA、“可延伸”内容和待补问题同样受内容锁定约束，不能因为标为草案、候选或参考句就免于事实审查。材料没有日期、场景、身体感、使用结果或普遍性证据时，不写“去年”“那天”“所有人都会”“确实有效”等补充；可以直接省略，或明确标成需要本人提供的素材缺口。

### 3. 深度对话

只有主题、缺少个人体验或关键判断时，先提出最少且关键的问题：

1. 你真正经历或观察到了什么？
2. 哪个具体瞬间改变了你的判断？
3. 哪句原话最值得保留？
4. 这个判断适用于谁，不适用于谁？

把口述当信息源，不把口述顺序直接当文章结构。核心判断应来自作者已经表达的内容；若需要模型归纳，必须标成候选并等待确认。

### 4. 大纲确认

完整成稿前先交付：

- 一句话核心判断，并注明来源与证据强度；
- 主类型 / 辅类型；
- 3–5 节公众号大纲和各节任务；
- 每节使用的真实证据；
- 开头入口、人物或问题主线、结尾方向；
- `[待补]`、隐私和授权风险；
- 与内容锁定单的差异。

使用者已提供或已确认完整大纲时可直接进入正文；否则大纲未确认不写完整正文。只有使用者明确要求跳过大纲确认时才可跳过，并保留风险说明。

### 5. 选择公众号骨架

按主类型选择默认骨架，再让结构服从材料：

| 主类型 | 常用骨架 |
| --- | --- |
| 工具 | 问题—方案—演示—边界 |
| 角度 | 常见看法—证据冲突—新判断—适用范围 |
| 余韵 | 具体入口—体验展开—内在变化—开放收束 |
| 系统 | 真实问题—多个判断递进—方法关系—使用边界 |
| 人物 | 冲突—选择—代价—变化—仍在继续的部分 |
| 专论 | 问题界定—主张—证据—反例—边界—结论 |
| 实录 | 起点—关键节点—决策变化—结果状态—复盘 |

每节只完成一个推进。输入是信息源，不是结构源；授权范本用于理解语感与成熟结构，不复制句子、私事或独特表达。

### 6. 初稿

- 用具体场景、动作、证据和推理承载判断；
- 一段只完成一个推进，长短服务阅读节奏；
- 保留作者真实原话的生命力，避免空泛悬念、对仗堆叠和无证据升华；
- 涉及人物时只写有来源且允许公开的内容，不代写他人内心；
- 涉及工具、方法或结果时写清条件、失败处和边界；
- 标题中的对象、冲突、经历、变化和收益必须在正文中出现。
- 素材不足以支撑目标长度时，宁可交付较短正文或保留 `[待补]`，不得用授权范本、常识或“合理想象”填充字数。

需要具体结构与句段检查时读取 [公众号长文与改稿](references/wechat-long-form-editing.md)。

### 7. 多轮改稿

已有草稿或连续反馈时，先建立“改稿状态卡”，再修改：

```text
标题承诺：
人物主线：
事件 / 机制线：
读者最终能带走的判断或动作：
每一节只负责什么：
当前最致命的问题：
本轮只解决：
```

按影响从大到小处理：

1. 主角、核心冲突和章节边界；
2. 章节推进与案例位置；
3. 事实、判断、证据强度和隐私；
4. 段落功能、语气和词句；
5. 标题、结尾、CTA 和发布包装。

每轮只处理 1–3 个最高优先问题。使用者只要求局部修改时，保持其他部分不动，不在润色中偷偷新增事实或改变立场。修改后重读相邻段落、整节和全文。

零新增编辑模式下，局部改写只能删句、重排、截取原句片段，以及调整标点、分段和小标题位置；不能把“补身体感”“增强画面”“增加互动”当成表达优化，也不能新增总结句、过渡句或升华句。交付前逐句执行文字级来源追踪：除小标题与必要标签外，正文每个连续文字片段都必须能在待改原文中找到；任何找不到的内容性片段都视为硬门失败。

逐句来源追踪至少检查每句新增的名词、动词、程度词、时间词、心理词和因果连接词。在默认抽取式编辑下，出现原文没有的内容词或连接句就退回原句或删除整句；不得用“这是原文情感方向”作为新写句子的理由。若无法在不新增内容的前提下完成理想结构，交付更小范围的编辑，并明确材料边界；不得用合理想象补齐。

局部改稿时，CTA 状态属于内容锁定项：原稿没有 CTA，且使用者说“不增加 CTA／不销售／不引流”时，终审写“不适用”，正文、改写、建议和备选方案都不得新增评论区、私信、加微信、关注、产品、课程或联系方式。通用发布规则里的默认入口不能覆盖本轮禁令。

CTA 不是所有文章的必填项。原稿无 CTA 且本轮禁止新增时，不得把“没有 CTA”诊断为问题，也不得用“欢迎来找我”“如果你也……”等软性邀请绕过禁令。

### 8. 事实与对抗审查

逐段检查：

- 事实、数字、原话、时间点是否能回到来源；
- 个人经历是否被不当拔高为普遍因果；
- 标题、开头、小标题和结尾是否被正文兑现；
- 陌生读者能否复述“发生了什么、为何这样、自己能带走什么”；
- 是否漏掉反例、条件、失败或代价；
- 人物、家庭、客户与业务隐私是否越界；
- 主角、核心判断和起心动念是否中途漂移；
- 系统、工具或技术线是否压过真正的人物和问题；
- 情绪高潮后是否先让判断落稳，再进入方法、产品或 CTA。
- 正文中每个第一人称事实、动机、感受、判断与因果是否能指向本次素材；
- 是否出现与授权范本相同或近义的内容性短语、观点、比喻、场景、CTA 或叙述判断；若有且本次素材没有独立来源，删除或标 `[待补]`。
- 零新增编辑模式下，新增的每个环境、身体、动作、心理、对话、比喻、因果与 CTA 是否逐句可回到待改原文；任一无法回读即退回，不得交付该句。

硬门失败时定向退回对应阶段，不整篇无差别重写。

不得用一句未经材料证明的“因果桥”修补结构断裂。例如，某次自我发现没有证据表明由 AI、课程或某个事件促成，就不能建议写成“因为 AI 整理后我才发现”。可选修复只有：补证、删减、重新排序、弱化因果或修改标题承诺。

### 9. 语感校准

对照本次已读的 1–2 篇同类型授权全文范本，只校准：句长与停顿、叙事距离、情绪温度、具体颗粒度、常用与禁用表达、留白和收尾方式。

当前原稿和作者本轮表达优先于风格摘要；风格摘要优先于外部文章。外部文章只能启发结构或问题意识，不能用来冒充作者语感。

校准结束后做一次“范本污染检查”：列出范本对本稿产生的影响，只能是抽象语感项；若能指出某个观点、比喻、事件、CTA 或内容性短语来自范本，本稿必须移除该内容，除非本次素材另有独立证据。

### 10. 标题、配图、排版与交接

标题确定后，再逐项列出标题承诺与正文兑现位置，并复查内容锁定差异。需要配图时，只规划与文章证据一致的真实材料或明确标注的说明性视觉：

- 真实经历优先使用已授权照片、原始记录或真实界面；
- AI 图片不得冒充生活现场、人物、聊天、软件界面或运行证据；
- 截图只保留支撑正文的最小区域，检查路径、凭据、账号、学校、客户和私人文件名；
- 每张图说明用途、插入位置、来源和授权状态。

CTA 必须来自使用者配置或本轮明确确认，先回答读者能得到什么、第一步做什么。未经确认不添加价格、名额、效果承诺或销售入口。本 Skill 不自动发布。

本轮明确说“不新增 CTA”时，该指令高于工作区的默认 CTA 和联系方式：不仅正文不添加，审稿建议、候选结尾、标题说明和“可选方案”中也不得建议评论、私信、加微信、关注、报名或其他转化动作。

### 11. 发布证据与回写

只有使用者明确确认已发布，或已提供可回读的平台原文链接／后台证据时，才可把状态写成已发布。配置中若有可选回写钩子，先展示拟写内容和目标位置，并在获得写入授权后执行。

最低发布证据：实际平台、发布时间、公开链接或等效后台证据、最终稿版本。草稿、预览、排版完成和待发布计划均不算已发布。缺少证据时只标“待回写”。

## 输出

按本次任务交付最小完整结果：

- **初始化模式**：配置缺口、授权范本要求、素材盘点、可选大纲与下一步；不输出完整正文。
- **大纲任务**：内容锁定单、核心判断、类型、结构、各节证据、待补与风险。
- **正文任务**：经确认的大纲、标题候选、正文、事实／待确认／不可公开清单、锁定差异、发布前最小验证。
- **多轮改稿**：改稿状态卡、本轮修改结果、未处理问题和锁定差异。
- **终审任务**：逐项门禁结果、阻断项和最小修复建议；未经要求不重写全文。

## 边界

- 只服务微信公众号长文，不承担朋友圈、小红书、视频脚本或其他平台改写。
- 不声称模型生成文字是作者原话，不搬运授权范本中的独特句子或私人事实。
- 不编造效果、收入、家庭、客户、健康、教育或业务案例。
- 不因追求传播扩大判断、制造焦虑或泄露隐私。
- 不把配置、范本或材料复制进公开 Skill、示例、日志或反馈表。
- 未经授权不修改原始素材、私人配置、知识库、发布台账或平台数据。
