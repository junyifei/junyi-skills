# 微信公众号长文协作

只维护一套公开执行方法。作者自己的定位、语料、路径、授权、范本和发布规则留在私人工作区，不复制进 Skill。

## 一、启动

1. 判断任务状态：初始化、素材到大纲、从零成稿、续写、多轮改稿、终审、标题或配图。
2. 只读取本轮明确授权的材料和配置，不搜索未授权目录。
3. 按 [配置契约](references/configuration-contract.md) 检查最小配置，并精确读取 1–2 篇本轮指定的同类型授权全文范本。指定范本定位不到时报告缺失，不用其他文章替代。
4. 缺少最小配置或至少一篇授权全文范本时进入初始化模式：只做缺口、素材盘点和可选大纲，不写个性化完整正文。
5. 从已完成状态继续，不机械重跑已确认步骤。

用户可见交付只显示安全文档名或来源标签，不回显绝对路径、用户目录、隐藏目录、临时目录和仓库位置。

## 二、执行优先级

本轮明确要求与授权 > 当前工作区规则 > 作者配置与授权范本 > 通用写作建议。

任何冲突都按高层执行。事实、隐私、状态、CTA 和授权是硬门；字数、画面感、情绪浓度和传播建议不能覆盖硬门。

授权范本只校准句长、停顿、叙事距离、情绪温度和收尾方式。不得迁移范本中的事实、观点、心理、比喻、金句、CTA 或内容性短语。

按任务读取：

- 事实、隐私与发布状态：[证据与隐私](references/evidence-and-privacy.md)
- 人群、因果与判断范围：[论断范围](references/claim-scope.md)
- 长文结构、多轮改稿与标题：[公众号长文与改稿](references/wechat-long-form-editing.md)

## 三、0—11 阶段

### 0. 起心动念

写清为什么现在写、最想让谁读、希望对方读完理解或采取什么行动。

### 1. 角度与类型

给 2–3 个有材料支撑的角度，选主类型与最多一个辅类型：工具、角度、余韵、系统、人物、专论、实录。没有范围证据时，角度型文章只是提供一个新区分，不声称修正“常见看法”。

### 2. 素材盘点与内容锁定

建立精简内容锁定单：目的、读者、类型、核心判断、来源、已确认事实与原话、作者判断、隐私、CTA、状态、论断范围、关键缺口。

事实、作者判断、推断、待确认和不可公开项分开。素材不足处删掉或标 `[待补]`，不编场景、心理、对话、数字、因果、结果或适用范围。

### 3. 深度对话

只有缺口会改变主轴、事实、隐私、CTA 或发布状态时才提问。最多 3 个，可以为 0；不默认索要身体感、戏剧场景或生活比喻。

### 4. 大纲确认

先给可读的编辑方案：推荐角度与核心判断 → 3–5 节推进 → 开头与结尾 → 标题 → 精简风险与必要问题。每节说清任务、材料和如何推进下一步。不要让合规字段淹没文章主线。

大纲未确认不写完整正文，除非使用者明确要求跳过。

### 5. 选择骨架

让结构服从材料：

| 类型 | 常用骨架 |
| --- | --- |
| 工具 | 问题—方案—演示—边界 |
| 角度 | 真实矛盾—新判断—证据—适用范围 |
| 余韵 | 具体入口—体验展开—变化—开放收束 |
| 系统 | 真实问题—判断递进—方法关系—边界 |
| 人物 | 冲突—选择—代价—变化 |
| 专论 | 界定—主张—证据—反例—边界 |
| 实录 | 起点—节点—决策—状态—复盘 |

### 6. 初稿

用本次材料中的场景、动作、证据和推理承载判断；一段只完成一个推进。术语先说人话。标题中的对象、冲突、变化和收益必须在正文出现。材料不足时宁可短或留 `[待补]`，不靠范本和合理想象凑字数。

### 7. 多轮改稿

先建立状态卡：标题承诺、人物主线、机制线、读者带走什么、各节任务、最致命问题、本轮只解决什么。

按主轴 → 结构 → 证据 → 段落 → 句子 → 包装处理。每轮只修 1–3 个最高影响问题；局部请求保持其他部分不动。

编辑判断可以明确指出主线延迟、章节漂移、证据过薄、信息密度和结尾外转，并标明原文依据。诊断可以有编辑判断，展示给作者的改写正文不能因此新增事实。

### 8. 事实与对抗审查

核查来源、因果、论断范围、标题兑现、人物隐私、主线漂移、系统是否压过人物、CTA 与发布状态。硬门失败时只退回对应段落。

以下任务必须经过**独立第二遍事实审稿**后才可展示：第一人称事实锁定改稿；含私人材料、候选／发布状态或人群范围的大纲；使用授权范本完成的完整正文。第一遍只负责编辑与写作，第二遍只拿“原始材料 + 本轮要求 + 第一遍草稿”逐项查新增事实、心理、时间、因果、范围、隐私、CTA、状态、范本污染和无效提问。

第二遍保持第一遍的结构与语气，只做最小删除、收窄或退回，不重新发挥。环境支持独立只读审稿上下文时使用独立上下文；若只能自审，先完成草稿但不展示，再按同一清单重新读取来源。没有完成第二遍时只能标“待事实审稿”，不能写“通过”。

环境允许时运行：

```bash
python3 scripts/check_output_guards.py <draft.md> --scope-evidence none --status candidate --cta none
```

按本轮材料调整参数。脚本通过不替代人工逐句回读。

### 9. 语感校准

只用本轮指定授权全文校准抽象语感。完成后检查范本污染；能指出来自范本的观点、比喻、事件、心理、CTA 或短语时，删除它。

### 10. 标题、配图与交接

逐项列出标题承诺与正文兑现位置。标题中的数字、时长、动作、心理、程度和状态都必须有材料来源。配图只用授权真实材料或明确标注的说明性视觉；AI 图不冒充现场、人物、界面或证据。本 Skill 不自动发布。

### 11. 发布证据与回写

只有使用者明确确认已发布，或提供平台链接／后台证据时，才可写“已发布”。回写前展示目标和拟写内容并取得授权。草稿、预览和排版完成不算发布。

## 四、事实锁定编辑

当使用者要求“不增加新事实”时，待改原文是唯一事实词典。

默认允许轻度转述、拆合句、删减和重排，但不能改变或新增人物、动作、对象、程度、时间、动机、情绪、判断、因果、比喻和 CTA。明确要求“抽取式／只删改重排／逐字保留”时，才进入严格抽取模式。

重点拦截隐蔽新增：原文没有时，不写“我停了一下、我原以为、没想到、后来才发现、第一次意识到、反复想过、终于明白、差点、用了几年”等心理、动作、时间和程度桥接。相邻两段不自动构成因果或转折。

原文没有 CTA 且本轮未授权新增时，正文、诊断、建议和备选方案都不引入 CTA，终审写“不适用”。

## 五、展示前硬门

先在内部审查并删除不合格候选，再输出。以下做法禁止：

- 写进一个无来源句子，再问作者“是否越界”；
- 展示含无来源数字、时间或心理的标题，再备注“确认后可用”；
- 用“常见看法、所有人、创作者通常、共同焦虑、读者会代入、共鸣最强／最宽、最快、一定”等无证据范围或最高级；
- 把“担心、不放心、怎么办”等情绪词误称为身体感；
- 为凑满三个而询问场景、体感、比喻或已在任务中确认的读者与 CTA。

如果某句需要作者补证，它不得出现在候选正文、开头、标题或 CTA 中；只在确实阻断下一阶段时列一个最小问题。

## 六、输出

- 初始化：配置缺口、素材盘点、可选大纲、下一步。
- 大纲：推荐角度、核心判断、章节推进、开头结尾、标题、精简内容锁定与风险、必要问题。
- 正文：已确认大纲、标题、正文、事实／待确认／不可公开、锁定差异、发布前验证。
- 多轮改稿：状态卡、3 个最高影响问题、修改结果、终审、未处理问题。
- 终审：门禁结果、阻断项、最小修复；未经要求不重写全文。

## 边界

- 只服务微信公众号长文，不承担朋友圈、小红书、视频脚本或其他平台。
- 不声称模型文字是作者原话，不复制授权范本中的独特表达或私人事实。
- 不编造效果、收入、家庭、客户、健康、教育或业务案例。
- 不把配置、范本和材料复制进公开 Skill、示例、日志或反馈表。
- 未经授权不修改素材、配置、知识库、台账或平台数据。
