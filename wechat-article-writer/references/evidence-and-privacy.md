# 证据、事实与隐私门禁

## 事实底稿

| 类别 | 处理方式 |
| --- | --- |
| 已确认事实 | 可写入正文，保留来源位置 |
| 作者判断 | 可表达，但不要伪装成外部事实或普遍规律 |
| 可核对原话 | 只有能回到原始记录时才使用引号 |
| 推断 | 标明推断主体与不确定性；发布前决定删除、弱化或补证 |
| 待确认 | 标 `[待确认]`，不得偷偷补全 |
| 不可公开 | 不进入正文；匿名后仍有风险时继续移除 |

来源通常按以下顺序判断：原始记录或本人确认 > 可定位正式材料 > 二手摘要 > 模型推断。摘要可帮助定位，不能替代原始证据。

路径与来源标签分开处理：代理可用获授权的路径读取材料，但面向使用者的内容锁定单、审稿报告和文章附件只写文档标题或来源标签，不回显绝对路径、用户目录、隐藏目录、临时目录、仓库检出位置或配置文件物理位置。无法确定安全标题时使用“本轮原始材料”“授权范本 1”等中性标签。

## 论断强度

- 单个经历支持“我观察到”“在这次经历里”，不能自动证明普遍规律。
- 时间先后不等于因果；没有证据时改写为相关、可能或待验证。
- 一个案例只承担它实际证明的结论。
- 已区分的测试类型、完成状态和证据等级必须保留原标签。
- 数字、排名、百分比、收入、效率和成果必须能回到来源，否则删除或标待核实。
- 转述不用引号；原话记录来源、日期和位置。
- “已完成”“已发布”“稳定有效”等状态必须有相应证据，不能由计划、草稿或单次反馈替代。
- 材料没有时间时不自行补“去年／最近／那天”；没有范围证据时不把单个经历写成“所有人都会／普遍如此”。
- 大纲示例句、候选开头、比喻、过渡、标题说明和 CTA 草案也属于待审内容，不能绕过事实、隐私和状态门禁。

## 人物与隐私

以下信息默认需要额外确认：儿童、伴侣、客户、健康、财务、冲突、联系方式、未公开业务数据、可识别第三方经历和私人文件路径。

处理顺序：

1. 确认事实来源与公开授权；
2. 判断姓名、机构、时间、地点和细节组合是否仍可识别；
3. 无授权时匿名化、概括或移除；
4. 匿名后仍可能伤害当事人或泄露关系时继续移除；
5. 无法确认时列为发布阻断项，不替使用者决定。

## 图片与附件

材料中出现图片不代表可公开使用。照片、截图、聊天记录、作品图和 AI 生成图分别核对所有权、肖像、隐私、真实性和发布授权。没有验证真实文件与授权时，只能列图片需求或占位说明，不得声称“图片已准备好”。

## 发布阻断项

出现以下任一情况，不得标为可直接发布：

- 核心事实依赖推断；
- 关键引语无法回到来源；
- 第三方授权不清；
- 标题承诺超出正文证据；
- CTA、价格、名额、效果或业务承诺未确认；
- 内容锁定单的关键变化未获确认；
- 私密信息仍可识别。

可以交付内部稿，但必须列明阻断项和最小补证动作。
