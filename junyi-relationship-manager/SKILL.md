# 记住每一个重要的人 · junyi-relationship-manager

你说一句话，Agent 帮你把这个人记下来、整理好，并提醒你该跟进谁、谁的需求可以对接。

> 一句话：你说一句话，它帮你把人记下来、提醒你该跟进谁、谁的需求能对接。

**为什么它属于「把自己活明白」**

活明白，不只是想清楚自己，也包括看清并用心对待身边的人：不把重要的人弄丢，把"认识很多人"变成"真的懂这些人"，并照见自己的心力到底流向了谁。这个 skill 就做这件事。资源撮合、健康度仪表盘是进阶功能，不是它的主线。

**做什么**
关系经营，五层能力——记录 + 需求标签 + 阶段跟进 + 资源撮合 + 健康度报告；可双写飞书多维表格（数据层）+ Obsidian 人物图谱（内容层）。

**什么时候用**
认识了新的人、聊完了一个人、想知道谁久没联系该跟进、想给两个人牵线时。
触发词：记一下XX、帮我更新关系、今天和XX聊了、新认识了一个人、关系更新、谁该跟进了、资源撮合、关系报告

**用完得到什么**
一份份有温度的关系档案 + 跟进提醒 + 资源撮合建议；进阶配好飞书后还有每周自动提醒和月报。

> **零基础先这样用**：直接说"记一下今天和张三聊了……"，AI 就把张三整理成一份关系档案（存成 markdown 文件）——这一步**不需要飞书、不需要任何配置**，开箱即用。
> 下面的「飞书双写 / 每周自动提醒 / 资源撮合 / 月报」是**进阶自动化**，等你配好飞书多维表格和定时任务后才会自动跑；没配也完全不影响你手动记录和随时查阅。

## 五层能力

| 层 | 做什么 | 触发方式 |
|---|---|---|
| L1 记录 | 双写飞书表+Obsidian | 你说关于某人的信息 → 自动 |
| L2 需求标签 | 从交流中提取需求关键词 | 记录时自动提取 |
| L3 阶段跟进 | 按关系阶段设定跟进节奏 | cron 每周扫描 |
| L4 资源撮合 | 匹配"A的需求"和"B能提供的" | cron 每周/手动 |
| L5 健康度报告 | 月度关系网络全景 | cron 每月/手动 |

## 系统架构

| 层 | 工具 | 存什么 | 回答什么 |
|---|---|---|---|
| 数据层 | 飞书多维表格 | 事实+状态+需求 | 谁该联系、谁需要什么 |
| 内容层 | Obsidian 人物图谱 | 故事+原话+感受 | 上次聊了什么 |

两层通过**姓名**锚定。

## 配置（进阶才需要——只手动记 markdown 可跳过）

想启用「飞书双写 / 自动提醒」时，才需要在 Agent 的配置文件（`TOOLS.md`，没有就新建一个）里填：

```
关系图谱 app_token: <你的飞书多维表格 app_token>
关系图谱 table_id: <你的 table_id>
人物图谱路径: <你的 vault 路径>/人物图谱/
```

## Obsidian 档案七段结构

仅亲密度 ≥ 4 的人建档。文件名 = 姓名.md。

```markdown
---
姓名: 张三
圈层: 朋友
关系类别: 同事
亲密度: 5
最近更新: 2026-06-20
---

# 张三

## 基本信息
- 称呼:
- 生日:
- 其他关键信息:

## 关系现状
- 上次深度交流:
- 上次交流话题:
- 一句话印象（瞬间/特质/状态）:
- 我的感受:

## 我的期待
- 希望这段关系变成什么样:
- 这段关系的意义（可选）:

## 素材库（持续养）
- TA 最近说过让我印象深刻的话:
- 我观察到 TA 最近在努力/在意的事:
- 一个让我既感动又心疼的瞬间:
- TA 最近的一个小变化:
- 我一直想对 TA 说但没说出口的话:

## 互动时间线
- YYYY-MM-DD: 一句话摘要

## 这周/这月的一件小事
-（一个具体的、能做的小行动）

## 关系里程碑
-（标志性时刻：第一次见面/重要事件/关系质变转折点）
```

## L1 双写决策树

```
1. 这个人在飞书表里有吗？
   ├── 没有 → 新增（必填：姓名/圈层/亲密度/关系阶段）
   │         → 亲密度 ≥ 4 → 同时建 Obsidian 档案
   └── 有 → 按信息类型写对应位置

2. 信息类型 → 写哪里？
   聊了什么         → 飞书表(交流时间+话题) + Obsidian(互动时间线)
   TA说了一句话     → 飞书表(一句话印象) + Obsidian(素材库)
   我的感受         → Obsidian(关系现状)
   TA的背景信息     → 飞书表(关键信息) + Obsidian(基本信息)
   TA的需求/痛点    → 飞书表(当前需求+紧迫度) + Obsidian(素材库)
   TA能提供的资源   → 飞书表(能提供的资源)
   标志性事件       → 飞书表(交流时间) + Obsidian(时间线+里程碑)
   新认识的人       → 飞书表新增（阶段=认识）

3. 自动提取需求标签（L2）：
   "想学AI" → 打标签"学AI"
   "在找XX资源" → 打标签"找资源"
   不确定 → 标"待挖掘"
```

## L3 关系阶段跟进策略

| 阶段 | 跟进节奏 | Agent 行为 |
|---|---|---|
| 认识 | 每2周 | 建议破冰话题 |
| 熟悉 | 每月 | 建议深入话题 |
| 信任 | 按事件驱动 | 有新信息时提醒 |
| 深度 | 按事件驱动 | 需求匹配+资源对接 |
| 核心 | 自然频率 | 生日/里程碑提醒 |

每周 cron 扫描：过期跟进 → 阶段超期 → 温和提醒。

## L4 资源撮合（进阶）

每周扫描"当前需求"和"能提供的资源"，匹配关键词交集。

```
🤝 资源撮合建议：
张三（需求：找设计师）↔ 李四（能提供：UI设计）
→ 建议：可以安排三人聊一下
```

铁律：只建议不执行（关系对接涉及人情判断）；双方亲密度都 ≥ 3 才撮合；同一对30天内不重复建议。

## L5 关系健康度月报（进阶）

每月1号自动生成，包含：
1. **网络概览**：总人数、圈层分布、阶段分布
2. **亲密度趋势**：升级/下降
3. **跟进执行率**：建议跟进X人，实际跟进X人
4. **需求闭环率**：有需求X人，已推进X人
5. **本月亮点**：新增关系、里程碑、成功撮合
6. **下月建议**：重点跟进、待挖掘需求

## 生命事件提醒

- 生日提前3天提醒
- 当天提醒
- 关系里程碑周年（标注后自动循环）

## 核心原则

- 100% 基于原话，不脑补不润色
- 素材库、互动时间线只追加不删除
- （进阶双写时）飞书表和 Obsidian 都写成功才算完成；只手动记 markdown 时，写成一份档案即可
- 资源撮合只建议不执行
- 需求标签只从明确交流中提取，不推测
- 这是私人关系档案：只在本地/你自己的知识库里记录，不外传、不用于任何未经对方知情的用途
